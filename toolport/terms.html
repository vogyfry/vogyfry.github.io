2. Description of Service

Prava Toolport is a desktop application that acts as a local semantic registry and broker between AI agents (MCP clients) and MCP servers. It indexes the tools exposed by servers you configure, lets a connected agent discover tools by semantic search, and proxies tool invocations to the appropriate downstream server. Search and indexing run locally on your device.
