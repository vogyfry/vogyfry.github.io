Set Up in Minutes

Install once. Works everywhere in Xcode.

1

Install SwiftMind

Download from the Mac App Store — the Prava Swift model comes with the install. SwiftMind lives in your menu bar and loads it on demand.

2

Add as Chat Provider

Open Xcode → Settings → Intelligence → Chat → Add a Chat Provider → Locally Hosted → port 1234. Done. SwiftMind now powers Xcode's Chat panel.

3

Turn On Agent Mode

In Xcode → Settings → Intelligence → MCP, enable Xcode Tools and Allow. Now type /build in the Chat panel to let SwiftMind write, build, and fix code for you.

4

Code Privately

Ask questions in the Chat panel, highlight code and right-click for commands. Everything runs on your Mac — no API key, no internet, no subscription.
