Frequently Asked Questions

What are the system requirements?

SwiftMind requires macOS 26+ and Apple Silicon (M2 or later) with at least 24 GB of unified memory. The on-device model needs roughly 8 GB of free disk and is delivered with the App Store install.

Does SwiftMind require an internet connection?

No. SwiftMind is fully offline. After installing from the Mac App Store, everything runs on your Mac. No API key, no internet connection, no subscription fees after purchase.

How do I add SwiftMind as a Chat Provider in Xcode?

Open Xcode → Settings → Intelligence → Chat → click "Add a Chat Provider…" → select "Locally Hosted" → enter port 1234 → Save. Make sure SwiftMind is running in your menu bar first.

How do I use Agent Mode?

In Xcode → Settings → Intelligence → MCP, enable Xcode Tools and choose Allow. Then type /build followed by what you want in the Chat panel — SwiftMind writes the code, builds it through Xcode, reads the diagnostics, and fixes errors in a loop until it compiles.

SwiftMind doesn't appear in Xcode's Chat panel — what's wrong?

  • Make sure SwiftMind is running (check your menu bar)
  • Wait for the menu bar icon to show "Model Loaded" status
  • Confirm the port in Xcode Settings → Intelligence → Chat matches (default: 1234)
  • Try quitting and relaunching both SwiftMind and Xcode

Do I have to wait for the model to load?

Usually not. SwiftMind pre-loads the model as soon as it detects Xcode running, so it's typically ready before you send your first message. The first cold load reads the model into memory (a few seconds), then it stays resident while you work and is released automatically when Xcode quits. The menu bar icon shows a loading state until inference is ready.

Can I change the port from 1234?

Yes. Open SwiftMind → Settings and set a custom port. Then update the matching port in Xcode → Settings → Intelligence → Chat.

Is my code private?

Yes. The HTTP server binds to 127.0.0.1 (loopback) only. Your code never leaves your Mac. See our Privacy Policy for full details.

The app is crashing or slow — what should I do?

  • Make sure you're running the latest version from the Mac App Store
  • Quit and relaunch SwiftMind
  • Check available disk space and RAM
  • If issues persist, email support@pravalabs.app with your Mac model, macOS version, and a description of the problem
